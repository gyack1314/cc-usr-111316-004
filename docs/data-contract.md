# 实施面板与推断口径

G为首次处理年或null(never)，不能同地区变化。每户每年一行，原始窗口完整；具体(g,t)取基期b=g-L-1与t共同家庭。district是赋值与推断聚类，不是每户单独随机化。处理组为G=g，对照never或G>t+L。

定义D=1(G=g)，在每格的处理和合法对照家庭上，m0(X)拟合对照的ΔY，p(X)为本格D的logit。折外得分ATT为处理组加权均值(ΔY-m0)减合法对照以p/(1-p)乘人口权重后的归一均值(ΔY-m0)。每格截距始终含在两模型内，不引入未经登记正则。真实完全分离或秩不足不可估。折按district固定，拟合训练不得包含评估地区；折中训练支持不足也不可估。

bootstrap用按地区生成0/2权重(1+Rademacher)，同地区全户全时同乘；重新执行拟合、格估计及固定队列聚合。固定原分析完整事件窗可估队列与其基期人口权重，原样本不存在支持不能靠重抽补救。以bootstrap居中标准化事件向量最大绝对值分位数构造同时带，退化坐标单独标记。bootstrap不可估次数与原因单列，不能只对成功次数假装全样本推断；不足声明有效次数时不发布区间。

原资料outcome仅为合成损失指标，无因果结论。读取器只核验JSONL身份、必要列和折形状，不拟合或估ATT。
